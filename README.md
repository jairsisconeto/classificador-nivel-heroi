# 🏆 Classificador de Nível de Herói

## 📌 Descrição
Este projeto é um **classificador de nível de herói**, baseado na **quantidade de XP** do personagem. Inicialmente, o desafio foi implementado apenas em **JavaScript**, mas depois evoluímos para incluir **HTML** e **CSS**, criando uma interface interativa e estilizada para tornar a experiência do usuário mais intuitiva.

## 🚀 Tecnologias Utilizadas
- **JavaScript** → Responsável pela lógica da classificação.
- **HTML** → Criou a estrutura da página.
- **CSS** → Melhorou o design e a usabilidade.
- **Git & GitHub** → Para versionamento e compartilhamento do projeto.

## 🎮 Como Funciona?
1️⃣ O usuário insere o **nome do herói** e a **quantidade de XP** no formulário.  
2️⃣ O JavaScript processa a informação e determina o **nível do herói**.  
3️⃣ O resultado é exibido diretamente na tela com um layout agradável.  

### 🔢 Classificação de Nível
| XP do Herói | Nível |
|-------------|-------|
| Menos de 1.000 | 🛠 Ferro |

| 2.001 a 5.000 | 🥈 Prata |
| 5.001 a 7.000 | 🥇 Ouro |
| 7.001 a 8.000 | 💎 Platina |
| 8.001 a 9.000 | 🌟 Ascendente |
| 9.001 a 10.000 | 🔥 Imortal |
| 10.001+ | 🏆 Radiante |

## 🚀 Como Executar o Projeto
1️⃣ Clone este repositório:  
```sh
git clone https://github.com/jairsisconeto/classificador-heroi.git
```
2️⃣ Abra o arquivo `index.html` no navegador.  
3️⃣ Insira o nome e XP do herói e clique em **Classificar**.
